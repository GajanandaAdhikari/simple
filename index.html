DevOps Project Showcase: Simple CI/CD

Project Name: Simple

Simple implementation of **Continuous Integration/Continuous Delivery (CI/CD)**, leveraging **Docker** for a reliable DevOps pipeline.

Jekyll Site CI Overview

This project successfully sets up Continuous Integration (CI) for a **Jekyll** static site using **GitHub Actions**. The site is automatically built and validated whenever changes are pushed to the `master` branch or a pull request is created, ensuring rapid feedback and quality control.

Key Features

  • **Automated Jekyll Site Builds:** Triggers automatically on push and pull request events.
  • **Consistent Build Environment:** Uses **Docker** to encapsulate the Jekyll build process, eliminating "it works on my machine" issues.

Technologies Used

  • Static Site Generator: Jekyll
  • CI/CD: GitHub Actions
  • Containerization: Docker

Workflow Configuration: CI Pipeline

The Continuous Integration workflow is defined in the file **`.github/workflows/ci.yml`**.

The pipeline is configured to:

  • Trigger on `push` and `pull_request` events targeting the `master` branch.
  • Build the Jekyll site using the official **`jekyll/builder` Docker image**, ensuring a clean and consistent build every time.
